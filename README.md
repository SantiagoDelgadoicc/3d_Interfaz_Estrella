# Magnus 3D Interface

Interfaz 3D desarrollada con Ursina para representar y controlar visualmente los módulos y capacidades de Magnus.

## Estado

En desarrollo.

Actualmente la interfaz funciona de forma independiente de Magnus utilizando datos de prueba.

## Tecnologías

- Python
- Ursina
- NetworkX

## Objetivo

Crear una interfaz 3D modular y flexible que posteriormente pueda integrarse con Magnus.
